# Resumen del proyecto

    El objetivo del proyecto es crear una web SPA para la gestión
    de alquileres de oficinas de una empresa no existente, frontend,
    backend y base de datos, a partir de JSX (Node, React, Vite)


## No olvidar
    dependencias para backend: npm i morgan express sequelize mysql2 dotenv jsonwebtoken bcrypt cors
    para frontend: npm i bootstrap toastify react-router jsonwebtoken
